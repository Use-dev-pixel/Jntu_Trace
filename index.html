Quick Start

Get up and running with JTrace in under a minute.

1. Download the app

Choose your platform from the download section. JTrace is available for macOS, Windows, and Linux. The bundled JDK means no separate Java installation is needed.

2. Launch JTrace

Open the app. You'll see the editor with a default "Hello World" program already loaded. The left sidebar shows your saved programs.

3. Write or paste Java code

Replace the default code with your own Java program. Make sure your file contains a main method:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, JTrace!");
    }
}
Package declarations are not supported. Keep your classes in the default package (no package statement at the top).

4. Run or trace

Click Run Console to compile and execute normally, or Trace Step-by-Step to record every state change for line‑by‑line inspection.

5. Save your work

JTrace auto‑saves your program as you type (after a short debounce). The first time you want to name a program, use the Save option. Saved programs appear in the sidebar for quick access.

Tracing Guide

The trace feature is the heart of JTrace. Here's how to make the most of it.

Starting a trace

Click Trace Step-by-Step in the bottom bar. JTrace will compile your program, execute it with instrumentation, and open the trace screen.

The trace screen layout

The trace screen has three main panels:

  • Code panel (left) — shows your source with the current line highlighted
  • Console panel (bottom‑left) — accumulated output up to the current step
  • Frames panel (right) — call stack with live variable values

Navigating steps

Use the step controls in the top bar to move forward and backward through recorded events. The current event is highlighted in blue, and any variables that changed glow briefly.

Inspecting variables

Each frame in the frames panel shows its local variables and arguments. Hover over a frame to expand it. The active frame is always expanded. Variables that changed on the current step get a subtle glow.

Return values

When a method returns, its frame moves to the "completed" section at the bottom of the frames panel, and the resolved return value is displayed. If the method is void, it shows "void".

Tip: Use the trace feature to understand tricky recursion, nested loops, and object state changes. It's like a debugger, but you can rewind.

Frequently Asked Questions

Does JTrace require Java to be installed?

No. JTrace bundles a minimal JDK (including javac and java). You don't need any external Java installation.

What Java version does JTrace use?

The bundled JDK is based on OpenJDK 17. It supports all modern Java features including records, sealed classes, and switch expressions.

Why doesn't my code with a package declaration work?

JTrace currently only supports the default package. Remove the package line from your source file. We're working on multi‑package support.

How does the trace feature work?

For most platforms, JTrace uses an interpreter that parses and executes your Java source directly, recording every step. On macOS and Windows, it can also use the native JDK pipeline for faster execution. The trace data is then presented in the trace screen.

Is my code sent anywhere?

No. Everything runs locally on your machine. JTrace never sends your code over the network. It's completely offline and privacy‑first.

Can I use JTrace for commercial projects?

Yes. JTrace is free to use for personal and commercial projects. It's provided as‑is by JSpiders JNTU.

How do I report a bug or request a feature?

Reach out to the JSpiders JNTU team through the contact link in the footer, or open an issue on our GitHub repository.
